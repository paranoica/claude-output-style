# Было → стало

Пары взяты из прогона стенда (`bench/results/v1`, первый прогон каждого промпта): «было» это чистый Claude Code, «стало» это он же с блоком из `CLAUDE.md`. Длинные ответы обрезаны, `…` отмечает пропуск. В скобках средняя длина ответа на этот промпт по трём прогонам.

Пары 1 и 2 в сокращённом виде вшиты в сам блок правил.

## 1. Выбор между вариантами (2225 → 971 символ)

> что взять для фоновых задач в небольшом fastapi проекте: celery, rq или arq? сервер один, задач ~1000 в день, редис уже есть

Было:

```markdown
**Рекомендация: arq**, если код задач асинхронный (httpx, asyncpg, async SQLAlchemy и т.п.). …

## Почему arq

- **Нативный asyncio.** Задачи — обычные `async def`, …
- **Лёгкий.** Одна зависимость поверх Redis, конфиг — класс `WorkerSettings` …
…
Если покажешь, что именно делают задачи (I/O или CPU, нужны ли retry, cron, результаты), могу сказать точнее.
```

Стало:

```markdown
arq, если код задач асинхронный (httpx, async ORM), rq, если синхронный. Celery для 1000 задач в день на одном сервере избыточен: отдельный брокерный слой, больше конфигурации, больше движущихся частей при той же пользе.

arq хорошо ложится на FastAPI. Задачи пишутся как обычные `async def`, …
```

Ушли заголовки, жирный на каждом пункте, длинные тире и хвост с предложением помощи.

## 2. Личный вопрос, написанный в разговорной манере (1941 → 1279)

> заебался уже, третью неделю не могу закрыть проект, клиент каждый день меняет требования. как с этим вообще жить

```markdown
Понимаю. Три недели «почти готово» выматывают сильнее, чем сама работа. …

**1. Зафиксировать, что такое «готово»**
…
**5. Посмотреть на договор**
…
```

```markdown
Зафиксируй письменно, что входит в текущую версию, и закрой её. Всё, что клиент присылает после этого, оформляй как отдельную задачу со своим сроком и ценой.

Сейчас проект не закрывается, потому что у него нет границы: …

Какой у вас формат оплаты: фикс за весь проект или почасовая?
```

Первая строка сразу даёт совет вместо «Понимаю». Вопрос один, а не три. Мата и сленга в ответ нет. Для сравнения, при старом стиле `humanized` в ответах на этот промпт проскакивало «норм».

```markdown
## Причина
```

Стало:
